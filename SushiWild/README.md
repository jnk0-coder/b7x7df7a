# 🍣 스시 와일드 (SUSHI WILD) — Unreal Engine 프로토타입 v0.1

`docs/comic-sushi-openworld-gdd.md` 기획서의 **8-3장 "프로토타입" 범위**를 Unreal Engine 5 C++로 옮긴 회색 박스 버전입니다.
맵·메시·UI 에셋이 하나도 없어도 돌아가도록 **섬 전체를 C++ 코드로 세웁니다** (엔진 기본 도형 사용).

> ⚠️ **솔직한 상태 보고**
> 이 코드는 Unreal Engine이 설치되지 않은 클라우드 환경에서 작성했습니다.
> - 밸런스 수식(`SushiBalance.h`)은 일반 C++ 테스트 35개로 **실제로 검증**했습니다.
> - 게임 코드 전체는 엔진 API를 흉내 낸 가짜 헤더로 **문법·오타 검사만** 통과했습니다.
> - **진짜 Unreal 빌드와 플레이는 아직 안 해 봤습니다.** 처음 빌드할 때 엔진 버전 차이로 자잘한 컴파일 에러가 날 수 있습니다.

---

## 1. 실행 방법

### 가장 쉬운 방법: 더블클릭 한 번 (Windows)
Unreal Engine 5.5 이상과 Visual Studio 2022("C++를 사용한 게임 개발")가 설치돼 있으면 됩니다.

- **`BuildAndPlay.bat`** 더블클릭 → 설치된 엔진을 찾고, 프로젝트 버전을 맞추고, 빌드한 뒤 **게임을 바로 켭니다.**
- **`OpenEditor.bat`** 더블클릭 → 같은 과정을 거친 뒤 **에디터**를 엽니다.
- 빌드가 실패하면 같은 폴더에 **`BuildLog.txt`** 가 생깁니다. 이 파일을 보내 주면 고쳐 드립니다.
- `SDK validation failed` 처럼 **C++ 도구나 Windows SDK가 없어서** 실패하면, 스크립트가 Visual Studio 부품(게임 개발 C++ · MSVC · Windows 11 SDK)을 대신 설치하고 다시 빌드할지 물어봅니다. 관리자 권한 창에서 "예"를 누르면 됩니다.

### 손으로 하는 방법
1. **Unreal Engine 5.5 이상**을 설치합니다 (Epic Games Launcher).
2. Windows라면 **Visual Studio 2022**를 설치합니다. 설치할 때 "C++를 사용한 게임 개발" 워크로드를 고릅니다.
3. `SushiWild/SushiWild.uproject`를 **오른쪽 클릭 → Generate Visual Studio project files**를 누릅니다.
   - 엔진 버전을 물어보면 설치한 버전(5.5, 5.6 …)을 고릅니다.
4. 생성된 `SushiWild.sln`을 열고 **Development Editor** 구성으로 빌드합니다.
   - 아니면 `.uproject`를 더블클릭해서 "다시 빌드하시겠습니까?"에 **예**를 눌러도 됩니다.
5. 에디터가 열리면 **Play(▶)** 를 누릅니다. 빈 맵(`/Engine/Maps/Entry`)에서 시작해서, 게임 모드가 섬을 자동으로 세웁니다.

### 한글이 네모(□)로 보이면
엔진 기본 폰트에 한글이 없는 환경도 있습니다. 그럴 땐 이렇게 합니다.

1. 한글 폰트(예: Noto Sans KR `.ttf`)를 콘텐츠 브라우저로 끌어다 놓아 임포트합니다.
2. `SushiHUD`를 부모로 하는 블루프린트를 만들고, **Korean Font Override**에 그 폰트를 넣습니다.
3. 게임 모드의 HUD 클래스를 그 블루프린트로 바꿉니다.

### 밸런스 수식 테스트 (엔진 없이)
```bash
cd SushiWild
g++ -std=c++17 -I Source/SushiWild/Public Tests/BalanceTest.cpp -o balance_test && ./balance_test
```

## 4. 구현된 것 (기획서 장 번호 대응)

| 3-4 마르코프 날씨 | 4시간마다 날씨 변화, 개굴레오의 "오늘 밤 비 확률" 예보. 안개 = 경비 시야 절반, 비 = 발소리 묻힘, 새벽 = 경비 졸음 | `SushiWildGameState` |
| 4-1 신선도 | `100 × ½^(t/반감기)`. 새우 6분, 참치 8분, 계란 30분 | `SushiBalance::Freshness` |
| 4-1 잡는 방식 = 품질 | 안 들키고 훔치면 +20, 리듬 낚시 +10 | `SushiCatalog` |
| 4-2 닭알 잠입 | 돈 꼬꼬레오네가 좌우로 훑어봄 + 20% 확률로 뒤돌아보는 척. 바닥에 시야 부채꼴(노랑→주황→빨강). E 꾹 눌러 알 빼기. 들키면 "꼬끼오!" 경보 → 병아리 떼가 쫓아와 쪼음. 옥수수 미끼에 병아리만 넘어감 | `KokoleoneNest`, `ChickGuard`, `SushiVisionComponent`, `CornBait` |
| 4-2 알 운반 | 뛰면 흔들림 게이지가 차서 깨짐, 가게에 들어가면 자동 보관 | `SushiChefCharacter` |
| 4-2 리듬 낚시 | 광어(발라드 70) · 고등어(트로트 130) · 연어(K-POP 120) · 장어(EDM 160) · 복어(레게 90). 줄 텐션 100이면 끊김 | `FishingSpot` |
| 5-3 샤리 쥐기 | 4박자 리듬. 일찍 누르면 돌덩이, 늦으면 공중분해 | `SushiCounter` |
| 5-4 와사비 룰렛 | 구간별 반응, 85% 넘으면 **손님 로켓 발사** → 맵 어딘가 추락 → 구출하면 단골. 러시안 와사비 10%. 날다람G는 로켓을 원함 | `SushiCounter`, `SushiCustomer` |
| 5-8 채점 | 재료 35 + 샤리 20 + 와사비 15 + 플레이팅 20 + 취향(코사인 유사도) 10, × 신선도 보정 | `SushiBalance::PlateScore` |
| 7-1 실패 연출 | 펠리컨 구급대(기절 → 가게 앞, 재료 30% 분실) · 간판 글자 떨어짐(초밥왕→초밥→밥→ㅂ, 가끔 "왕밥초") · 의자 뜯어 먹는 손님 · 바다 빠지면 갈매기 구조 · 현상수배 포스터 · 상한 재료 = 화장실 대기줄 | 여러 곳 |

## 5. 아직 안 된 것 (v0.2 이후)

- 참치 레슬링, 멧돼지 추격전, 소 목장 결투, 그 밖의 재료 미션 (기획서 4-2 하단 표)
- 물리 엔진 플레이팅 (지금은 플레이팅 점수 70 고정)
- VIP 퀘스트 6종, 포아송 돌발 이벤트 (수식은 `SushiBalance`에 있고 테스트도 통과. 게임에 연결만 남음)
- 가게 6단계 업그레이드, 스킬 트리, 직원 고용, 저장/불러오기
- 전설 오징어 등 날씨 한정 변종, 도감 화면
- 진짜 아트(캐릭터 모델·애니메이션·사운드). 지금은 전부 기본 도형입니다.
